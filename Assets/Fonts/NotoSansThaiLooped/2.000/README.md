# Noto Sans Thai Looped 2.000

This directory vendors the Regular and Bold static TTF files from the official
`NotoSansThaiLooped-v2.000` release. The font is licensed separately from
PrintGateway under the SIL Open Font License 1.1; see `OFL.txt`.

The exact source URLs and SHA-256 checksums are recorded in
`font-manifest.json`. Runtime rendering must load these files directly and must
not silently fall back to an operating-system font.
